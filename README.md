#Win Defender Update

Win Defender Update — небольшой open-source инструмент для Windows, предназначенный для контроля состояния Microsoft Defender и помощи в поддержании его защитных компонентов в актуальном состоянии.

«⚠️ Проект находится в разработке. Используйте его на тестовых системах на свой риск.»

🛡️ Что делает Win Defender Update

Win Defender Update помогает пользователю:

- проверять, установлен ли Microsoft Defender;
- проверять состояние Microsoft Defender;
- отображать версию Defender;
- проверять актуальность защитных обновлений;
- показывать дату последнего обновления;
- запускать доступные официальные механизмы обновления Defender;
- запускать проверку системы через Microsoft Defender;
- сообщать о проблемах с защитой;
- обнаруживать сторонние антивирусные программы и предупреждать о возможных конфликтах.

🔄 Безопасное обновление

Win Defender Update не должен бездумно заменять компоненты Defender.

Перед обновлением программа должна:

1. проверить текущую версию;
2. проверить состояние Defender;
3. определить наличие доступного обновления;
4. сообщить пользователю, что будет изменено;
5. выполнить обновление через официальные механизмы Windows;
6. повторно проверить состояние после обновления.

Если обновление невозможно или существует риск нарушения работы Defender, программа должна остановить операцию и сообщить пользователю об ошибке.

📦 Сторонние антивирусы

Win Defender Update может обнаруживать сторонние антивирусные программы.

Программа не должна принудительно удалять их без подтверждения пользователя.

Если обнаружен сторонний антивирус, пользователь получает предупреждение и может самостоятельно решить, удалить его или оставить.

💻 Командная строка

Некоторые операции проекта могут выполняться через Windows Command Prompt (".bat") и официальные инструменты Windows.

Win Defender Update должен проверять результат выполнения команд, а не просто показывать сообщение:

"Operation completed successfully"

Если команда завершилась ошибкой, программа должна показать реальный результат и сообщить пользователю, что операция не выполнена.

🚧 Требования

- Windows 10 или более новая версия Windows;
- установленный и доступный Microsoft Defender;
- права администратора для операций, которым они действительно необходимы.

Если Microsoft Defender отсутствует или недоступен, Win Defender Update не должен притворяться, что он работает. Пользователю должно быть показано соответствующее сообщение.
